%   Kp = 0.5       % 比例系数 (Proportional gain)

% 温度范围 (Temperature Range):

%   3. 能效比 (Efficiency): (1440-violations) / cost

% Q2: 如何与DQN对比?
% A2: 运行 compareStrategies.m
%     它会同时运行DQN和PID，生成对比报告

% Q3: 为什么PID和DQN结果不同?
% A3: - DQN使用神经网络学习策略
%     - PID使用固定的经典控制算法
%     - 两种方法各有优缺点

% Q4: 如何调优PID参数?

%     - 每个scenario运行720步(12小时)
